# Homebrew tap for Throughline

```bash
brew install sarthakpattnaik1/throughline/throughline
throughline
```

`throughline` sets Throughline up in `~/throughline-os` the first time and starts
it; after that the same command starts it and says when a newer release is
published. Your research data lives in `~/.throughline-os`, and
`brew uninstall throughline` never touches it.

**Why a tap.** Homebrew does not quarantine what a formula installs, so nothing
here meets Gatekeeper's "cannot be opened" wall — the durable way onto a Mac
without a paid Apple signing certificate.

**Where this comes from.** `Formula/throughline.rb` is generated by
`scripts/homebrew.py` in the Throughline repository from the release manifest,
after its Ed25519 signature is checked against the release key. It pins the
versioned archive and its checksum, and installs only that release's launcher.
Do not edit it by hand; regenerate it.
